# Bean Rooted Café Website

This is the standalone website for Bean Rooted Café. All CSS, JavaScript, and supplied café photos are embedded in `index.html`.

## Publish with GitHub Pages
1. Create a new **public** repository on GitHub, for example `bean-rooted-cafe`.
2. Upload `index.html` to the top level of the repository (not inside another folder).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then click **Save**.
6. Wait for the Pages deployment. Your public website address will be shown in the Pages section and will usually look like `https://YOUR-USERNAME.github.io/bean-rooted-cafe/`.

The menu prices in the sample site are illustrative; confirm them with the café before treating them as official.
